Sizes and loading

  • 163 SVG files in public/icons/spells/: 1326 KB, 287 KB as sent (gzipped), about 7.0 KB a hero.
  • Nothing is fetched when the page opens: a hero's four files are asked for the first time one of its slots is drawn (the spell bar, the Play screen, the Heroes table, the Shop). Until they arrive, or if one fails, the old canvas icon is drawn, and the new picture replaces it in the same place.
  • The page's start grows by about half a kilobyte (the list of drawn heroes and the loader).
  • The code: src/icons/vc.ts (the loader) and two lines in src/heroes.ts that call it. Nothing else in the game changed.

Remaking an icon

Each hero's drawing is pipeline/icons/vectorcraft/draw/<hero>.py; the shared rules are in vclib.py. python pipeline/icons/vectorcraft/make.py <hero> [slot] writes the command file and runs VectorCraft, and adds the hero to the game's list. page.py <batch> remakes a batch page, overview.py this one.
