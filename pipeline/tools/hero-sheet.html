Hero model sheets (dev server only: http://localhost:5173/pipeline/tools/hero-sheet.html). It imports only the hero figure, so saving a kit file elsewhere does not reload it. From the browser tool:

await _sheet([['Silvane old', 'models/heroes/mirror_v2.glb'], ['Silvane NEW', 'models/heroes/mirror_v3.glb']])  // -> size; image in window._jpg
window._jpg                                   // return this to save it (the tool writes big results to a file)
await _tris('models/heroes/mirror_v3.glb')    // triangle count
await _size('models/heroes/mirror_v3.glb')    // { r90, y99 }: radial 90th percentile and height 99th percentile of the vertices

Rows: the front at eye height; then the game camera (55° down) from the front and from behind. Labels with NEW are gold, (ref) blue. Every load adds a query string, so a re-exported model is fetched again.
