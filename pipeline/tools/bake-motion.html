Reads animation clips from the KayKit Character Animations pack (CC0, pipeline/assets/kaykit/) and writes what the game's own rig can replay (src/motion/kaykit.json, read by src/motion/clips.ts). Dev server only: http://localhost:5175/pipeline/tools/bake-motion.html. From the browser tool:

await _bake()            // every clip in CLIPS -> the JSON text in window._json (return it; the tool saves it to a file)
await _mannequin('Melee_2H_Attack_Chop', 16)   // 16 frames of the pack's own mannequin, from its right side -> window._jpg
await _mannequin('Melee_2H_Attack_Chop', 12, { stick: 1.3, from: 0.33, to: 1.43, w: 200, h: 220, cols: 6 })   // with a stick in its right hand

Per frame, in the character's own frame (X its left, Y up, Z forward): how far the hips are from where they rest (in leg lengths), how the hips, chest and head are turned from rest, which way each upper arm, forearm, thigh and shin points, how each foot is turned from rest, and which way each hand's item points.
