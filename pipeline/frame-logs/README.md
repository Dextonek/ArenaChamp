# Frame logs

Our own written notes from studying reference VFX frame by frame (no copied text or images).

- `youtube-i/<videoId>.md`: one per YouTube video in `pipeline/library/batch-i.json`. Each has a frame table
  (time | what is on screen | visible layers | what changed) plus technique notes. The video is
  `https://www.youtube.com/watch?v=<videoId>`.
- `style-notes/`: the style notes the video agents wrote for batches d–g (the user's own reference videos). They
  are condensed into `docs/VFX_PRINCIPLES.md` §7–§10.

Use these when a recipe is not detailed enough: they show the exact frame order the recipe was made from.
